# moddex-discord

The Discord bot behind [moddex.tv](https://moddex.tv), a reverse index of Twitch
moderator and VIP roles.

Announces new members and server boosts in the community server, and answers
`/health` so the status page can watch it. Holds no database and reads whatever
it needs from **api.moddex.tv**.

Documentation for the whole project lives in the `moddex-workspace` repository.
